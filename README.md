# Attrition Predictor

An AI-powered HR tool that predicts which employees are at risk of leaving. The model scores each employee by flight risk level, surfaces the key drivers behind each score, and recommends targeted HR interventions.

## Features
- Employee flight risk scoring — High / Low
- 5-year behavioural trend per department and individual employee
- Top attrition drivers with SHAP-based feature importance
- Department heatmap
- Rule-based HR interventions per department
- Department and role level filters

## Tech Stack
- Python · Streamlit · scikit-learn · pandas · SHAP

## Notes
- This is a proof of concept using synthetic data
- In production connects directly to your HRIS
- Version 0 — rule-based interventions
